# Status vocabulary

## Document lifecycle

Suggested labels:

```text
DRAFT
OPEN FOR DISCUSSION
COMMUNITY REVIEW
REVISED
RELEASE CANDIDATE
RELEASED
CURRENT
SUPERSEDED
DEPRECATED
ARCHIVED
```

These labels describe the document.

## Claim or component status

Suggested labels:

```text
OBSERVED
MEASURED
CALCULATED
IMPLEMENTED
DEMONSTRATED
REPRODUCED
INDEPENDENTLY VERIFIED
INFERRED
HYPOTHESISED
PROPOSED
EXPERIMENTAL
IN PROGRESS
PLANNED
NOT YET VALIDATED
SUPERSEDED
```

These labels describe a claim, component, experiment, or implementation.

## Important distinction

A document can be released while describing planned work.

Example:

```text
Document status: RELEASED
Component status: PLANNED
```

A deployed implementation can still lack scientific validation.

Example:

```text
Implementation status: DEMONSTRATED
Scientific validation: NOT YET COMPLETED
```
