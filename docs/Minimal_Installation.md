# Ubuntu/Debian minimal installation

```
sudo apt-get update
sudo apt-get install -y \
  texlive-latex-base \
  texlive-latex-recommended \
  texlive-latex-extra \
  texlive-fonts-recommended \
  texlive-pictures \
  lmodern
```

## Optional convenience tool:

```
sudo apt-get install -y latexmk
```
