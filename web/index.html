The current scientific-paper profile focuses on blockchain, computer science, chemistry, biochemistry and biology. It provides two-column reading, numbered equations and compounds, language-aware code, wide figures and optional exact artifact references without making every paper about GenesisL1.

03 / Build model

Preprocess once. Serve static files only.

  1. Build device: runs make all, compiles, packages and audits.
  2. Web device: receives only the generated web/ directory.
  3. Nginx: serves the files read-only; no TeX or build tools are required.
